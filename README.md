# Tower crane materials

Course files only. Each course uses:

- `lesson/` — PowerPoint (and PDF export if we have one)
- `slides/` — stills used to build the deck
- `assessments/` — written tests, answer keys, solution graphics

## Layout

```
tower-crane/
  load-charts/
    flattop/
      lesson/          Reading Tower Crane Load Charts.pptx + .pdf
      slides/lesson/   named stills (part2–part5, bonus, practice)
      slides/source/   raw ChatGPT image exports
      assessments/     Liebherr 71 EC-B 5, Potain MDT 218 A J10, Terex CTT 91-5
    luffing/
      lesson/          Luffing Tower Crane Charts.pptx
  climbing/
    lesson/            Tower Crane Climbing — BC Regulations & Red Seal.pptx + .pdf
    slides/            climbing stills
    assessments/       Red Seal Task C-7 written test + answer key
    photos/
reference/
  datasheets/          Liebherr, Potain, Terex manufacturer PDFs
  photos/
```
